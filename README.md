# Rodgers Biwott Portfolio

Static, accessible professional portfolio for Senior DevOps, DevSecOps, SRE and Platform Engineering roles.

The site includes verified career history and skills from the 2026 CV, plus an engineering case study for ObserveX. It uses semantic HTML, hand-authored responsive CSS and a small progressive-enhancement JavaScript file with no build-time dependencies.

## Local preview

```sh
python3 -m http.server 8090
```

Open `http://127.0.0.1:8090/`.

Live at [kiplongu.github.io](https://kiplongu.github.io/).
